# Keepy 캐릭터 공간 구현

## 영역과 동작

| 영역 | 코드 | 역할과 진입 |
| --- | --- | --- |
| 지켜보는 얼굴 | `app/lib/widgets/companion_header.dart` | 할 일 화면 위 큰 얼굴. 완료한 일의 조각이 아래 경계에 모임. 아래로 당기거나 탭하면 방을 연다. |
| 작업 영역 | `app/lib/pages/main_page.dart` | 흰 배경의 할 일 목록. 기존 입력창·태그 선택·카메라·분류·하단 탭을 유지한다. |
| 캐릭터 방 | `app/lib/pages/companion_room.dart` | 루트 내비게이터를 덮는 전체 화면. 단색의 방 배경과 캐릭터, 전달 연출, 상단의 짧은 활동 막대를 표시한다. 위로 밀거나 왼쪽 위 화살표로 복귀한다. |
| 기록과 보상 | `app/lib/pages/progress_page.dart` | 방 오른쪽 위 그래프 버튼으로 진입. 주간/월간 보고서, 연속 기록, 업적, 캐릭터 선택을 제공한다. |
| 할 일 편집 | `app/lib/widgets/task_editor.dart` | 블록 터치 → 제목·복수 태그·빠른 날짜·월 달력 → 저장. 취소하면 변경하지 않는다. |

방은 기록을 읽기 위한 패널이 아니다. 숫자와 설명은 별도 기록 화면에 두고, 방에는 아이콘과 막대만 보인다. 아이콘의 의미와 수량은 툴팁·접근성 레이블로 제공한다. 작업 화면은 방 아래에서 유지되므로 작성 중인 입력과 태그가 돌아온 뒤에도 남는다.

## 할 일 블록 조작

- 왼쪽으로 밀기: 오늘 기준 +1일 / +2일 / +7일을 거리로 선택하고 손을 놓으면 적용한다. 서윤 쪽 조작 흐름을 반영했다.
- 태그 수정: 블록을 눌러 편집창에서 여러 태그를 선택한다.
- 유지한 희일 기능: 체크 지연 확정과 실행 취소, 오른쪽 삭제 스냅/끝까지 밀어 삭제, 조작 중 위·아래로 벗어나 취소, 화면 밖으로 나간 삭제 패널 닫기, 목록·입력 영역에서 좌우 탭 전환.
- 캐릭터 방 제스처는 상단 캐릭터 영역에서만 받는다. 작업 블록을 아래로 벗어나 취소하는 동작과 구분한다.

## 캐릭터와 활동 추상화

`CompanionKind`는 교체 가능한 동물 종류, `ActivityKind`는 동물과 독립적인 작업 분류다. 임시 강아지/고양이를 제공하며 최종 캐릭터 선택을 확정한 것은 아니다.

| 기존 태그 | 통합 활동 | 임시 소품 |
| --- | --- | --- |
| 팀 프로젝트 | 협업 | 자료판 |
| 과제·수업 | 학습 | 학사모 |
| 개인 | 생활 | 장바구니 |
| 태그 없음 | 기타 | 기본 모습 |

복수 태그는 협업 → 학습 → 생활 → 기타 순으로 하나의 활동에 분류하여 한 일을 중복 집계하지 않는다. 완료 당시의 분류를 기록한다. 방의 소품은 최근 7일 중 가장 많은 활동을 따른다.

그림은 `CompanionArt(kind, faceOnly, joy, activity)`로 분리했다. 데이터·제스처를 바꾸지 않고 이 렌더러와 방 배경을 실제 일러스트·스프라이트·애니메이션으로 교체할 수 있다. 현재 그림은 구조 검증용 벡터이며, 전달 경로와 기쁜 표정/꼬리 반응만 기본 연출로 구현했다. OS의 모션 줄이기는 새 방 전환·전달·얼굴 반응에 반영된다.

## 성취·기록 정책

- `Task.credit`에는 완료일, 통합 활동, 전달 완료일을 저장한다. 별도의 최근 완료 내역 100개 제한과 관계없이 집계한다.
- 완료 → 대기 조각 생성 → 방 진입 시 전달 표시를 저장 → 조각 이동과 캐릭터 반응. 다시 열면 같은 조각을 재전달하지 않는다.
- 완료 취소는 현재 통계와 대기 조각에서 빠진다. 이미 전달한 표시를 유지해 체크를 반복해도 추가 지급하지 않는다.
- 완료 항목 삭제/비우기는 기존 tombstone 방식으로 보관하므로 장기 성취는 유지한다.
- 연속 기록은 그날 예정한 일을 모두 완료한 날에 증가한다. 늦게 완료한 일은 실제 완료일 통계에만 들어가며 지난날의 미달성을 뒤집지 않는다.
- 미확정 예외의 초기 정책: 일정이 없는 날은 쉬는 날로 증가도 단절도 하지 않는다. 당일 목표는 현재 일정에 맞춰 갱신하고 지난날의 저장된 목표 스냅샷은 고정한다. 당일 추가/삭제/일정 변경은 목표 분모에 영향을 준다.
- 보상: 누적 1/10/30/100개와 연속 3/7/14/30일. 획득한 보상은 유지한다. 화분·쿠션·조명은 방에도 나타난다.
- 주간/월간 보고서는 실제 완료일의 합계·활동 분포와 예정일의 계획 달성률을 구분한다. 이전 기간 비교는 같은 경과일 기준이다.

## 저장과 범위

성취 필드는 기존 작업 JSON 및 작업 동기화 경로를 사용한다. 캐릭터 선택, 일별 목표 스냅샷, 획득 보상은 기존 settings에 로컬 저장한다. 설정의 계정별 서버 동기화와 다중 오프라인 기기 간 원자적 보상 지급은 이번 구현에 포함되지 않는다. 기존 계정 전환/로컬 저장소 정책도 그대로다.

업그레이드 이전 완료 항목에 완료 시각이 있으면 이미 전달된 성취로 읽는다. 완료 시각이 없는 샘플·구형 항목의 날짜를 임의로 생성하지 않는다. 과거 편집 이력이 없는 데이터에서 과거 계획의 완전한 복원은 불가능하다.
