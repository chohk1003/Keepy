# Keepy 캐릭터 공간 구현

## 영역과 동작

| 영역 | 코드 | 역할과 진입 |
| --- | --- | --- |
| 캐릭터 영역 | `app/lib/widgets/companion_header.dart` | 할 일 화면 위 짙은 보라 띠(`K.room`). 노랑은 캐릭터 전용(`K.duck`)이라 띠에는 쓰지 않는다. 왼쪽에 **얼굴·상반신만**(가슴 아래는 띠 끝에서 잘려 빼꼼 보인다), 오른쪽에 오늘 날짜·완료율과 **태그별 막대**. 아래로 당기거나 탭하면 방을 연다. 할 일을 끝내면 그 자리에서 바로 반응한다(전달 단계 없음). |
| 작업 영역 | `app/lib/pages/main_page.dart` | 흰 배경의 할 일 목록. 기존 입력창·태그 선택·카메라·분류·하단 탭을 유지한다. |
| 캐릭터 방 | `app/lib/pages/companion_room.dart` | 루트 내비게이터를 덮는 전체 화면이자 **통계 화면**. 장면이 화면을 가득 채우고 그 위에 유리 카드 두 장 — 위는 7일 막대그래프(`week_activity_graph.dart`), 아래는 그 날의 태그별 통계. 좌우로 밀면 날짜가 바뀌고 그래프는 그대로다. 위로 밀거나 ∧ 버튼으로 복귀한다. |
| 기록과 보상 | `app/lib/pages/progress_page.dart` | 방 오른쪽 위 그래프 버튼으로 진입. 주간/월간 보고서, 연속 기록, 업적, 캐릭터 선택을 제공한다. |
| 할 일 편집 | `app/lib/widgets/task_editor.dart` | 블록 터치 → 제목·복수 태그·빠른 날짜·월 달력 → 저장. 취소하면 변경하지 않는다. |

방은 **일별 통계를 보는 곳**이다 (요구사항 '캐릭터패널'). 그래프 막대를 누르거나 좌우로 밀어 날짜를 바꾸면 장면과 아래 태그 통계가 그 날 것으로 바뀌고, 그래프 자체는 유지된다. 긴 설명·업적·주간/월간 보고서는 여전히 별도 기록 화면(`progress_page.dart`)에 둔다. 작업 화면은 방 아래에서 유지되므로 작성 중인 입력과 태그가 돌아온 뒤에도 남는다.

그래프는 **얇은 세로선 막대 + 정점을 잇는 하얀 선**(각 정점에 하얀 점)이고, 주식창처럼 **오늘이 맨 오른쪽**이다. 막대 색은 그 7일에서 많이 쓴 **상위 3개 태그**만 쓰고 나머지는 회색(기타)으로 묶는다 — 색이 늘어나 읽기 어려워지는 것을 막기 위해서다. 세는 수 자체는 태그 그대로다.

## 할 일 블록 조작

- 왼쪽으로 밀기: 오늘 기준 +1일 / +2일 / +7일을 거리로 선택하고 손을 놓으면 적용한다. 서윤 쪽 조작 흐름을 반영했다.
- 태그 수정: 블록을 눌러 편집창에서 여러 태그를 선택한다.
- 유지한 희일 기능: 체크 지연 확정과 실행 취소, 오른쪽 삭제 스냅/끝까지 밀어 삭제, 조작 중 위·아래로 벗어나 취소, 화면 밖으로 나간 삭제 패널 닫기, 목록·입력 영역에서 좌우 탭 전환.
- 캐릭터 방 제스처는 상단 캐릭터 영역에서만 받는다. 작업 블록을 아래로 벗어나 취소하는 동작과 구분한다.

## 캐릭터와 활동 추상화

캐릭터는 **노란 오리 하나**다 (서윤님 v0.7.0 벡터 그림, `widgets/duck_art.dart`). 동물 선택은 없앴다. `ActivityKind`는 캐릭터와 독립적인 작업 분류로, 장면과 '기록과 보상'의 활동 통계에만 쓴다 — 사용자에게 보이는 일일 통계는 태그 그대로 센다.

| 기존 태그 | 통합 활동 | 기록 화면 아이콘 |
| --- | --- | --- |
| 팀 프로젝트 | 협업 | 사람 둘 |
| 과제·수업 | 학습 | 책 |
| 개인 | 생활 | 집 |
| 태그 없음 | 기타 | 반짝임 |

복수 태그는 협업 → 학습 → 생활 → 기타 순으로 하나의 활동에 분류하여 한 일을 중복 집계하지 않는다. 완료 당시의 분류를 기록한다.

방의 **장면은 그 날 완료율**로 정해진다 (`duckSceneOf`, `widgets/room_scene.dart`).

| 완료율 | 장면 |
| --- | --- |
| 50% 미만 (할 일 0개 포함) | 자는 방 — 파자마 오리가 이불을 덮고 Zzz |
| 50% 이상 | 책상 — 셔츠·넥타이 오리가 노트북·커피·스탠드 |
| 100% | 수영장 — 선글라스·튜브, 탭하면 그 자리로 둥실 |

다크 테마에서는 같은 장면이 밤이 된다 (`RoomSim.night`).

그림은 `CompanionArt(faceOnly, bust, joy)`로 분리했다 — `bust`가 메인화면의 상반신 구도다. 데이터·제스처를 바꾸지 않고 이 렌더러와 방 배경을 교체할 수 있다. OS의 모션 줄이기는 방 전환·얼굴 반응에 반영된다.

## 성취·기록 정책

- `Task.credit`에는 완료일과 통합 활동을 저장한다. 별도의 최근 완료 내역 100개 제한과 관계없이 집계한다.
  (`deliveredAt` 은 없앤 '부스러기 전달' 연출의 자리다. 이미 저장된 기록이 있어 형식만 남겨 두고 읽고 다시 쓴다.)
- 완료하면 그 자리에서 캐릭터가 바로 반응한다. 전달 단계도, 대기 조각도 없다.
- 완료 취소는 현재 통계에서 빠지고, 다시 체크해도 성취는 하나로만 센다.
- 완료 항목 삭제/비우기는 기존 tombstone 방식으로 보관하므로 장기 성취는 유지한다.
- 연속 기록은 그날 예정한 일을 모두 완료한 날에 증가한다. 늦게 완료한 일은 실제 완료일 통계에만 들어가며 지난날의 미달성을 뒤집지 않는다.
- 미확정 예외의 초기 정책: 일정이 없는 날은 쉬는 날로 증가도 단절도 하지 않는다. 당일 목표는 현재 일정에 맞춰 갱신하고 지난날의 저장된 목표 스냅샷은 고정한다. 당일 추가/삭제/일정 변경은 목표 분모에 영향을 준다.
- 보상: 누적 1/10/30/100개와 연속 3/7/14/30일. 획득한 보상은 유지한다. 화분·쿠션·조명은 방에도 나타난다.
- 주간/월간 보고서는 실제 완료일의 합계·활동 분포와 예정일의 계획 달성률을 구분한다. 이전 기간 비교는 같은 경과일 기준이다.

## 저장과 범위

성취 필드는 기존 작업 JSON 및 작업 동기화 경로를 사용한다. 캐릭터 선택, 일별 목표 스냅샷, 획득 보상은 기존 settings에 로컬 저장한다. 설정의 계정별 서버 동기화와 다중 오프라인 기기 간 원자적 보상 지급은 이번 구현에 포함되지 않는다. 기존 계정 전환/로컬 저장소 정책도 그대로다.

업그레이드 이전 완료 항목에 완료 시각이 있으면 그 시각의 성취로 읽는다. 완료 시각이 없는 샘플·구형 항목의 날짜를 임의로 생성하지 않는다. 과거 편집 이력이 없는 데이터에서 과거 계획의 완전한 복원은 불가능하다.
