# Keepy (키피) — 저장되는 할 일 앱

> 주제 #2109 할 일 앱 – BaaS, AI 활용 · **미니프로젝트 2단계: 저장되는 앱으로 만들기**
> (1단계 '할 일 앱 화면 만들기'의 결과물 위에 이어서 작업)

Keepy 는 Flutter 로 만든 할 일 앱입니다. 할 일을 추가·완료·수정·삭제하고 전체/미완료/완료로 걸러 볼 수 있으며,
**앱을 껐다 켜도 데이터가 그대로 남도록 기기 안(shared_preferences)에 저장**합니다.

- 앱 전체 기능과 구조 총정리: [README_KEEPY.md](README_KEEPY.md)
- AI 사용 기록: [prompts_log.md](prompts_log.md)
- 화면 캡처: [screenshots/](screenshots/)
- 웹 미리보기(설치 없이 바로 보기): https://claude.ai/artifact/2uLyzxLpBx1YZS2ohDySXb

## 1. 실행 절차

**필요한 것:** Flutter stable 3.47.9 (팀 공통), Android Studio 에뮬레이터·실기기 또는 Chrome

```powershell
# 1) 소스 위치로 이동
cd C:\Keepy1\app

# 2) 플랫폼 폴더(android/ios/web) 생성 + 패키지 설치 (처음 한 번)
powershell -ExecutionPolicy Bypass -File tool\setup_platforms.ps1
#    macOS: bash tool/setup_platforms.sh
#    직접 하려면: flutter create . --project-name keepy --platforms=android,ios,web  →  flutter pub get

# 3) 검사
flutter analyze
flutter test

# 4) 실행
flutter run              # 에뮬레이터 / 실기기
flutter run -d chrome    # 웹 (빠른 확인용)
```

**데이터 유지 확인 방법:** 할 일을 몇 개 추가·완료한 뒤 앱을 완전히 종료(최근 앱에서 밀어서 닫기)하고 다시 실행 → 그대로 남아 있음.

## 2. 구현 기능 목록

### 1단계 (MP1) — 목록 + 입력 + 상태 변화
| 기능 | 설명 |
|---|---|
| 목록 화면 | 메인 화면에 '지연 → 해야 할 일 → 완료한 일' 순으로 할 일 표시, 전체 개수 배지 |
| 추가 입력 | 하단 고정 입력 바 → 전송(↑) 또는 키보드 완료로 추가. 공백 제외 1~100자일 때만 추가, 빈 입력은 흔들림 + 안내 |
| 완료 토글 | 둥근 네모 체크박스를 누르면 즉시 체크·취소선 → '완료한 일'로 이동, 다시 누르면 되돌림. 0.6초 동안 '취소' 가능 |
| 빈 상태 안내 | 할 일이 없으면 "등록된 태스크가 없습니다 / 기억하고 싶은 할 일이 있나요? / 아래에서 첫 태스크를 추가해 보세요" |
| 상태 관리 | `TaskStore`(ChangeNotifier) 한곳에서 변경 → 화면이 `ListenableBuilder` 로 즉시 반영 |

### 2단계 (MP2) — 저장 + CRUD + 필터
| 기능 | 설명 |
|---|---|
| **로컬 저장** | 모든 변경 직후 `shared_preferences` 에 JSON 으로 저장, 앱 시작 시 불러오기 → **재시작 후에도 유지** |
| **수정 (U)** | 할 일을 누르면 수정 시트: 제목, 태그, 기한(오늘·내일·모레·다음 주 칩 / 한 달 달력에서 한 번에) |
| **삭제 (D)** | 할 일을 오른쪽으로 밀면 삭제 버튼 → 누르거나, 절반 넘게 세게 밀면 즉시 삭제. 수정 시트의 휴지통으로도 삭제. 0.6초 '취소' |
| **필터** | 메인 상단 **전체 / 미완료 / 완료** 탭, 각 개수 실시간 표시 |
| 생성·조회 (C, R) | 1단계 입력 바·목록 그대로 |

### 그 밖에 구현된 것 (선택 확장)
오늘 요약 카드(눌러서 이동), 완료한 일 접기·비우기(되돌리기), 날짜 화면(캘린더 + 날짜별 목록), 왼쪽으로 당겨 +1/+2/+7일 지정, 편집 모드에서 끌어서 순서 바꾸기, 태그 관리(추가·이름 변경·삭제·순서),
지연/늦은 완료 자동 분류, 다크 모드, 카메라 OCR(종이 메모 → 할 일), 미니게임(계단 오르기) — 자세한 내용은 [README_KEEPY.md](README_KEEPY.md).

```
 ┌── 설정 ──┐   ┌── 메인 ──┐   ┌── 날짜 ──┐        좌우로 밀거나 하단 탭으로 이동

 │ 미니게임  │   │ /완료 탭  │   │ 할 일 목록│
 └──────────┘   │ [입력 바] │   │ [입력 바] │
                └──────────┘   └──────────┘
```

| 화면 | 주요 요소 |
|---|---|
| 메인 | 로고, 오늘 날짜, '모든 할 일 N' + 편집, 전체/미완료/완료 탭, 구역별 목록, 하단 입력 바·카메라, 하단 탭 바 |
| 수정 시트 | 제목 입력(1~100자, 글자 수), 태그 칩 + ⚙ 태그 관리, 기한(빠른 칩·한 달 달력), 저장·삭제 |
| 날짜 | 위 1/4 캘린더(제목을 누르면 한 달 전체), 완료율, 그날 할 일 |
| 설정 | 화면 모드(시스템/라이트/다크), 알림, 서비스 연동, 날짜 화면 옵션, 지연 기준, 태그, 미니게임, 완료 기록, 데이터 |

## 4. 저장 방식 — 대안 비교와 선택 이유

### 비교

| 방식 | 장점 | 단점 | Keepy 에 맞나 |
|---|---|---|---|
| **shared_preferences** (선택) | 설정 거의 없이 바로 사용, Android·iOS·**웹**·데스크톱 모두 지원, 코드 생성 불필요 | 키-값 저장이라 검색·정렬 쿼리 없음, 저장할 때마다 목록 전체를 다시 씀, 대용량 부적합 | ◎ 데이터가 작고 구조가 단순 |
| sqflite (SQLite) | 표·인덱스·SQL 쿼리, 대용량·부분 수정에 강함 | 웹 기본 미지원, 테이블 설계·SQL·마이그레이션 코드 필요 | △ 지금 규모엔 과함 |
| Hive / Isar (임베디드 NoSQL) | 빠름, 객체 단위 저장 | 어댑터·코드 생성(build_runner) 필요, 패키지 유지보수 상태를 따져야 함 | △ 의존성·설정 부담 |
| drift (SQLite + 타입 안전) | 쿼리 타입 검사, 반응형 스트림 | 코드 생성·학습 비용이 큼 | ✕ 2단계 범위를 넘음 |
| JSON 파일 (path_provider) | 형식 자유, 사람이 읽기 쉬움 | 파일 입출력·동시 쓰기·깨짐 처리 직접 구현, 웹 미지원 | △ |

### 선택 이유
1. **데이터가 작고 단순하다** — 할 일 1개가 JSON 약 200바이트, 수백 개여도 수십 KB 수준. 목록 전체를 한 번에 읽고 쓰는 방식으로 충분히 빠르다.
2. **모든 실행 환경에서 같은 코드** — 팀원이 에뮬레이터·실기기·`flutter run -d chrome` 어디서 확인하든 동일하게 저장된다. (sqflite 는 웹이 안 됨)
3. **설정·코드 생성이 없다** — 2단계 목표(CRUD·필터·재시작 유지)에 집중할 수 있다.
4. **나중에 바꾸기 쉽다** — 화면은 저장 방식을 모르고 `TaskRepository` 인터페이스만 쓴다. 할 일이 아주 많아지면 sqflite 로,
   3단계(BaaS 동기화)에서는 원격 저장소를 같은 인터페이스로 붙이면 된다.

### 단점을 줄이기 위해 한 것
- 저장 요청을 **순서대로 이어 붙여**(`TaskStore._commit`) 늦게 끝난 이전 저장이 최신 값을 덮지 않게 함
- 저장된 값이 깨져 있으면 지우지 않고 **별도 키에 백업**한 뒤 빈 목록으로 시작 (`LocalTaskRepository.loadTasks`)
- 할 일마다 `updatedAt`(마지막 수정 시각)을 저장해 3단계 동기화 때 병합 기준으로 쓸 수 있게 함

### 저장 구조
| 키 | 내용 |
|---|---|
| `keepy.tasks.v1` | 할 일 목록 JSON 배열 — `id, title, done, createdAt, completedAt, due(yyyy-MM-dd), tags, completedLate, updatedAt, order` |
| `keepy.settings.v1` | 설정 JSON — 화면 모드, 알림, 달력 옵션, 지연 기준, 태그 목록, 미니게임 등 |

관련 코드: `app/lib/data/repositories.dart`(계약), `app/lib/data/local_repositories.dart`(구현), `app/lib/state/task_store.dart`(변경·저장)
