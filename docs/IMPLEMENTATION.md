**해석해서 정한 것**
- 요청 3의 "+1/+2/+7일까지만"은 **세 단계(+1, +2, +7)** 로 해석했습니다. 1~7일 전부로 바꾸려면
  `TaskTile.dateStops` 를 `<int>[1, 2, 3, 4, 5, 6, 7]` 로 고치면 됩니다 (한 줄).
- 요청 3의 '메인 화면'의 스와이프는 날짜 화면의 할 일 블럭에도 똑같이 적용했습니다 (같은 블럭 위젯).
- 요청 7의 '11월 동안' → **이번 달**: 기한이 이번 달이거나, 기한 없이 이번 달에 만든 할 일.
- 순서 바꾸기를 넣으면서 미완료 정렬은 '지연 먼저 → 사용자가 정한 순서'로 바뀌었습니다 (전에는 기한 빠른 순).
- 날짜 화면 1/4 고정(CST-01)은 접힌 기본 상태에서 그대로 지키고, 사용자가 제목을 눌러 펼쳤을 때만 늘어납니다.
- 사람 분할 AI 는 Android/iOS 에서만 동작합니다. 웹·데스크톱(와 웹 미리보기)은 사진 테두리 색을 배경으로 보고 지우는 방식으로 대신합니다.
