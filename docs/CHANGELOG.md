# Changelog

## 0.5.0 — 2026-11-15

**미니게임**
- 나와 펫이 **같은 칸에 나란히** 서서 함께 깡충 오름 (이전: 펫이 한 칸 뒤에서 따라옴)
- 캐릭터·펫을 더 귀엽고 둥글게 다시 그림: 16×16 둥근 얼굴, 부드러운 남색 외곽선, 눈 반짝임·볼터치, 펫 12×12 둥근 몸
- **겹침 없애기:** 칸 폭 최소(펫 있으면 72, 없으면 54)를 두고, 할 일이 많아 화면을 넘으면 카메라가 캐릭터를 따라감
  (가로·세로). 캐릭터·펫 크기는 칸 폭에 맞추고, 그림의 '보이는 폭'을 재서 [펫][간격][캐릭터] 를 한 칸 안에 배치
- 만세 팔을 몸 가장자리에 붙이고, 정상 깃발은 오른쪽 바깥으로 펄럭여 머리와 겹치지 않게

**실용성**
- 메인에 **오늘 요약** 카드: 오늘 할 일 / 지연 / 오늘 완료. 누르면 각각 날짜 화면의 오늘 / 미완료 탭 / 완료 탭으로
- **완료한 일** 구역 접기·펼치기, **비우기**(완료한 일 한 번에 지우기, 확인 후 '취소'로 되돌리기)

**디자인**
- 카드에 아주 옅은 테두리를 넣어 바탕과 경계를 또렷하게 (라이트·다크 각각 다른 농도)

**버그 수정 (PC 첫 실행 후)**
- 첫 `flutter run -d chrome` 컴파일 오류: 미니게임 파일 수정 중 `StairPainter`·`StairMood`·`_MessageCard` 선언이 지워졌던 것을 복원
- 미니게임 꾸미기 시트 아래 'BOTTOM OVERFLOWED BY 25 PIXELS': 기본 시트 높이 제한(화면의 9/16)을 풀고(`isScrollControlled`), 화면이 낮으면 시트 안에서 스크롤

**문서**
- README 2종·IMPLEMENTATION·PROMPTS·prompts_log(26~33) 갱신, 스크린샷 20장(오늘 요약·비우기 확인 추가)

## 0.4.0 — 2026-11-15

**할 일 수정**
- 제목 글자가 안 보이던 문제 수정 (웹 미리보기: iOS 에서 글자 선택 막기가 입력 칸 글자를 숨기던 문제)
- 기한: 연·월·일 휠 대신 오늘·내일·모레·다음 주·없음 칩 + 한 달 달력에서 한 번에 고르기
- 태그 관리: ≡ 손잡이로 끌어 태그 순서 바꾸기 (입력 바·수정 시트 칩 순서에 반영)

**미니게임**
- 꾸미기: 캐릭터 남자 / 여자 / 내 사진, 펫 없음 / 강아지 / 고양이 / 토끼 (펫은 한 칸 뒤에서 따라 오름)
- 진행 막대, '오늘 +N칸', 다크 모드에서 별·달 밤하늘, 정상 도착 시 펫도 함께 점프

**제출 구조 (MP1·MP2)**
- Flutter 소스를 `app/` 으로, `README.md`(MP2 제출용)·`README_KEEPY.md`(총정리)·`prompts_log.md`·`screenshots/` 를 최상위로
- 저장 방식 대안 비교·선택 이유, 통과 기준 자체 점검표, 스크린샷 18장, prompts_log 14~25 추가

## 0.3.0 — 2026-11-15

**디자인**
- 메인 색을 하늘색·파란색 그라데이션으로, 바탕을 하늘빛 회청색으로
- 글꼴을 나눔스퀘어라운드(미세하게 둥근 고딕, OFL)로, 글자 크기를 전체적으로 한 단계 작게

**조작**
- 할 일 ← 당기기: 날짜만, 거리에 따라 +1 → +2 → +7일 단계, 누른 채 아래로 내리면 취소
  ([날짜][태그] 버튼·다이얼·태그 패널 삭제)
- 메인 '편집' 모드: ≡ 손잡이로 끌어 순서 바꾸기 (`Task.order` 저장)
- 날짜 화면 '년 월' 제목을 누르면 한 달 전체 펼치기/접기, < > 는 달 단위

**기능**
- 태그 관리(⚙): 추가·이름 변경·삭제, 할 일에도 반영 — 할 일 수정 시트와 설정에서 열기
- 미니게임 '계단 오르기': 설정에서 켜기/끄기, 메인 바로가기, 이번 달 완료율만큼 계단 오르기,
  100% 정상 도착 모션 / 미달 격려 모션, 사진 → 온디바이스 AI 사람 분할 → 24×24 픽셀 캐릭터

**문서**
- README 전면 갱신, IMPLEMENTATION 에 v0.3 대응표, docs/PROMPTS.md 를 프롬프트 가이드로 확장
