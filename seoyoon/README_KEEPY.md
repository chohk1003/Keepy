# Keepy (키피) — 총정리

> 제스처 중심 할 일 앱 · 팀 프로젝트 #2109 · Flutter · **v0.7.0** (2026-11-23)
>
> 제출용 문서(3단계)는 [README.md](README.md), 이 문서는 지금까지 만든 Keepy 전체를 한눈에 보는 정리본입니다.

메인 화면을 가운데 두고 왼쪽 **설정**, 오른쪽 **날짜** 화면을 넘겨 쓰는 3단 구조의 할 일 앱입니다.
할 일 블럭을 당겨서 날짜를 바꾸고, 종이 메모를 찍어 할 일로 바꾸고, 오늘 끝낸 만큼
**오리 수영장**에 물이 차올라 성취감을 줍니다. 로고 옆 **오늘 통계**로 오늘 어떤 태그의 일을 많이 했는지도 볼 수 있습니다 (v0.7).
로그인하면 **여러 기기에서 같은 목록**을 보고, 오프라인에서 쓴 할 일도 연결되면 서버에 올라갑니다 (v0.6, Supabase).

## 4. 조작

| 조작 | 동작 |
|---|---|
| 할 일 **← 당기기** | 날짜만 설정. 거리에 따라 **+1 → +2 → +7일** 단계마다 걸리고, 놓으면 저장 |
| 당기는 중 **아래로 내리기** | 취소 (아무것도 안 바뀜) |
| 할 일 **→ 당기기** | 삭제 버튼에 걸림 · 누르거나 절반 넘게 세게 끌고 놓으면 삭제 |
| **편집** (메인) | ≡ 손잡이로 구역 안 순서 바꾸기 |
| 할 일 누르기 | 수정 시트 · 태그 옆 **⚙** → 태그 추가·이름 변경·삭제·**≡ 끌어 순서 변경** |
| 기한 줄 누르기 | **오늘·내일·모레·다음 주·없음** 칩 또는 달력에서 날짜 한 번 누르기 |
| **오늘 요약** 칸 누르기 | 오늘 할 일 → 날짜 화면의 오늘 · 지연 → 미완료 탭 · 오늘 완료 → 완료 탭 |
| **완료한 일** 머리 누르기 / **비우기** | 접기·펼치기 / 완료한 일 모두 지우기 (확인 후, 알림의 '취소'로 되돌리기) |
| 체크박스 | 완료 (0.6초 '취소', 다른 곳 누르면 알림 즉시 닫힘) |
| 좌우로 밀기 (빈 곳·입력 바 위·리스트 맨 아래) | 화면 전환 / 하단 탭 |
| 날짜 화면 목록 끝에서 위·아래로 더 끌기 | 할 일이 있는 이전·다음 날로 |
| 날짜 화면 **'2026년 11월'** 누르기 | 한 달 전체 펼치기 ↔ 접기 |

## 5. 오리 수영장 · 오늘 통계 (v0.7, 미니게임 대체)

**오늘의 할 일** = 오늘이 기한인 일 + 기한 없이 오늘 만든 일 + 오늘 끝낸 일. 수영장과 통계가 같은 기준을 씁니다.

**오리 수영장**
- **켜기:** 설정 > 오리 수영장. 켜면 메인 오른쪽 위(옛 미니게임 자리)에 **오리 얼굴 아이콘**, 끄면 사라짐. 카메라처럼 따로 뜨는 화면이고 X 로 나감.
- 텅 빈 수영장에 **오늘 완료율만큼 물이 차오름** (부드럽게 차오르는 애니메이션).

| 오늘 완료율 | 화면 |
|---|---|
| 할 일 0개 또는 완료 0개 | 텅 빈 수영장, 오리가 바닥에 서서 콩콩 |
| 50% 미만 | 물이 조금 참, 오리는 바닥에 서 있음 |
| 50% 이상 | 물이 반 이상, 오리가 둥둥 떠다님 |
| **100%** | 물이 가득, **선글라스 오리 + 분홍 튜브 + 칵테일 + 반짝이**. **휴대폰을 기울이면** 그쪽으로 둥실 미끄러지고, **웹·PC 에서는 클릭한 쪽으로** 이동 |

**오늘 통계**
- 메인 'keepy' 로고 옆 **[오늘 통계 ⌄]** 를 누르면 날짜 화면의 월 캘린더처럼 **그 자리에서 펼쳐짐** (다시 누르면 접힘, 따로 된 화면 아님).
- 안경 + 학사모를 쓰고 엄지를 척 든 오리, '오늘 가장 많이 한 일 #태그', 오늘 완료율.
- 태그별 막대: 그 태그의 오늘 할 일 수(옅게) 위에 끝낸 수(진하게). 사용자가 만든 태그도 모두 세고, **많은 순 최대 5개** (같으면 끝낸 수 → 태그 목록 순). 나머지 태그 수·태그 없는 일 수는 아래에 한 줄로.

> 한성대 마스코트 '한성부기'는 실제 캐릭터라 그리지 않고, 직접 만든 노란 오리 캐릭터를 씁니다.

## 6. 다크 모드 (v0.4)

- 설정 > 화면 > **시스템 / 라이트 / 다크**. 시스템은 휴대폰 설정을 따라가고, 휴대폰에서 바꾸면 바로 반영.
- 바탕·카드·글자·구분선·캘린더 농도·탭 바·수영장 배경이 함께 바뀌고, 하늘색→파란색 강조는 두 모드 공통.
- 모드를 바꿔도 보던 탭이 유지됨.

## 6-1. 서버 동기화 (v0.6 · 미니프로젝트 3단계)

| 할 일 | 방법 |
|---|---|
| 켜기 | `app/.env` 에 Supabase 주소·공개 키 → `flutter run -d chrome --dart-define-from-file=.env` ([매뉴얼](docs/MP3_실행_매뉴얼.md)) |
| 로그인 | 설정 > 계정 → 회원가입 / 로그인 (다른 기기에서 같은 계정) |
| 상태 보기 | 메인 오른쪽 위 ☁ 배지: ✓ 맞춰짐 · ↻ 동기화 중 · ↑N 올릴 변경 · 오프라인 · 오류. 누르면 계정 · 동기화 시트 |
| 바로 맞추기 | 계정 시트의 **지금 동기화** (자동: 앱 시작·복귀, 변경 1.2초 뒤, 20초마다) |
| 오프라인 | 그냥 쓰면 됨. 기기에 모아 두었다가 연결되면 자동으로 올림 (앱을 꺼도 유지) |
| 같은 할 일을 두 기기에서 고치면 | 나중에 고친 쪽이 남음 (README 4절) |
| 로그아웃 | 이 기기의 할 일은 남음. 다시 로그인하면 계정과 합쳐짐 |

설정 키가 없으면 동기화만 꺼지고 나머지는 2단계와 똑같이 이 기기에 저장됩니다.

## 7. 프로젝트 구조

```
seoyoon/                         팀 저장소의 개인 폴더 (로컬 원본 C:\Keepy1 과 내용 같음)
├─ README.md / README_KEEPY.md / prompts_log.md / screenshots/
├─ app/                          Flutter 앱
│  ├─ lib/
│  │  ├─ main.dart, app.dart     시작 · 화면 모드 · 동기화 연결 · MaterialApp
│  │  ├─ core/                   theme(라이트·다크 팔레트, 글꼴, 모션), shadows, dates, env(설정 키)
│  │  ├─ models/                 Task(순서), TaskStatus(지연·늦은 완료), AppSettings(화면 모드·태그·수영장 켜기)
│  │  ├─ data/                   저장소 계약 + shared_preferences 구현
│  │  ├─ state/                  TaskStore, SettingsStore, SyncController(동기화), KeepyScope
│  │  ├─ services/               OCR, 이미지 삭제, sync/(Supabase REST·장부)
│  │  ├─ game/duck_painter.dart  오리 캐릭터 그림 (수영장·통계·아이콘)
│  │  └─ ui/  shell · pages · widgets(task_tile, mini_calendar, tag_manager_sheet …) · game(pool_page) · ocr
│  ├─ supabase/schema.sql        서버 표·보안 규칙·충돌 처리 트리거
│  ├─ test/                      모델·스토어·순서·태그·오늘 통계·그림자·위젯(수영장·통계)·동기화(두 기기·오프라인·충돌)
│  ├─ assets/fonts/              나눔스퀘어라운드 R/B/EB + OFL 라이선스
│  └─ tool/                      플랫폼 설정 스크립트
├─ preview/                      웹 미리보기 (index.html + 글꼴 일부)
└─ docs/                         MP3 실행 매뉴얼, 단계별 정리, MP3 프롬프트, IMPLEMENTATION, CHANGELOG, MODIFY_GUIDE, PROMPTS, TEAM_NOTES
```

의존 방향: `ui → state → data/models`, `ui → services → game`, `SyncController → TaskStore · services/sync`. 화면은 저장·동기화 방식을 모릅니다.
