### v0.3.0 — 디자인·조작·미니게임 (2026-11-15)

```
1. 전반적인 ui 미감이 아쉬워. 색감(메인 색은 하늘색/파란색 계열로), 폰트(아주 미세한 둥근 고딕 느낌) 등 수정해.

3. 메인 화면에서 태스크 우->좌 땡기면 날짜 설정만 나오게 해. 땡기는 정도에 따라 +1/+2/+7일까지만 하고,
   누른 상태에서 아래로 땡기면 하던 것 무효되도록 해.
4. 메인 화면 할 일 수정에서 태그 부분에 톱니바퀴 모양 추가해서 사용자가 태그를 추가 또는 기존 태그 이름 변경 및
   삭제 등 할 수 있게 해. 수정 모드일 때 태스크끼리 드래그해서 순서도 바꿀 수 있도록 해.
5. 날짜 화면에서 캘린더 부분 '2026년 11월' 글자 클릭하면 캘린더 1달 짜리 전부 볼 수 있도록 해.
   이럼 자연스럽게 캘린더 밑에 있는 완료율 및 태스크 등 영역이 줄어들겠지?
6. 메인 화면에 조그맣게 미니게임 바로가기 아이콘을 만들어. 참고로 미니게임은 설정 화면에서 사용자가 원하면
   뜨게 하고, 원하지 않으면 미니게임은 꺼.
7. 미니게임은 사용자의 성취감을 위함이야. 간단하게 사용자 사진을 ai로 픽셀화하여 만든 캐릭터가 계단을 올라가는
   것을 구현하려고 해. 계단 수는 사용자가 입력한 태스크 수와 동일하고, 전체 태스크 수(미완료/지연 포함)에서
   완료된 태스크 수 비율이야. 당연히 태스크 1개 완료 시 계단 1칸 올라가. 그래서 11월 동안 완료율이 100% 경우,
   정상에 도달하여 좋아하는 모션이 나와. 반대로 완료율 100% 못 찍으면 정상에는 도달 못하지만,
   격려 문구와 함께 모션이 나오도록 해.
8. 미니게임 화면은 설정/메인/날짜에 구애받지 않는 또 다른 영역으로 간주해. 마치 카메라 화면과 같아.
   언제든지 X 눌러서 미니게임을 나갈 수 있어.
9. 정확히 무엇을 구현하였는지, 어떤 점이 새롭게 추가되었는지 등 정리하며 해당 프로젝트 내용과 구조를 정리한
   README.md 파일과 프롬포트 가이드도 마지막에 준비해.
```

### v0.7.0 — 미니게임 → 오리 수영장 · 오늘 통계 (2026-11-23)

참고: 유튜브 영상(캐릭터에 물이 차오르는 할 일 앱 아이디어), 사용자 스케치(학사모·안경 오리 + 태그 통계 카드)

```
전반적인 아이디어만 참고하고 세부사항은 바꿀게. 3번은 사진을 참고해.
1. 카피바라 말고 한성대학교 마스코트인 한성부기로 해. 불가능하면 미니 게임에서 만들었던 동물들처럼 가상의 동물 캐릭터로 만들어. 그건 오리가 좋겠어.
2. 기존 메인 화면에서 미니 게임 아이콘을 해당 상호작용 이벤트로 바꾸고, 아이콘 모양은 캐릭터 얼굴로 하고, 위치는 그대로 두자.
3. 날짜 화면에서 최상단 날짜를 누르면 월 캘린더 영역이 확장되잖아? 이 기능과 유사하게 메인 화면에서 Keepy 글자 옆이든 최상단 토글 버튼이든(이건 너의 판단에 맡길게) 하나를 만들어서 그걸 클릭하면 통계 화면이 나올 거야. 이 통계 화면은 당일 등록된(하루에 포함되는) 태스크들을 태그 별로 정리하여 오늘은 어떤 태그에 해당하는 일을 많이 했는지 볼 수 있게 하는 거야. 화면은 메인/날짜/설정 화면처럼 따로 분리된 영역이 아니고, 날짜 화면에서 캘린더가 확장되는 것처럼 확장 개념이야. 우리가 만든 동물 캐릭터가 안경을 쓰고 엄지를 척 들고 있는 모습과, 각 태그 별 통계를 기록해. 사용자가 자유롭게 추가한 태그 역시 전부 포함해야 하고 단, 태그 숫자가 너무 많으면 화면에 다 담을 수 없으니 최다 순으로 최대 5개까지만 표시하자.
4. 본격적인 이벤트 내용을 정리할게. 진행도는 캐릭터를 물로 채우는 것이 아니라, 수영장 물을 채우는 거야. 텅 빈 수영장에서 태스크 완료율에 따라 물이 점점 차오르며, 최종적으로 100% 달성 시 물이 가득 차서 캐릭터가 둥둥 떠다니는 거야.
- 초기(오늘 등록된 태스크 0개 또는 아직 완료된 태스크 0개): 텅 빈 수영장에서 캐릭터가 귀엽게 서 있는 화면
- 완료율 50% 이상: 물이 반 정도 차 있고, 캐릭터가 귀엽게 떠다니는 화면
- 완료율 100%: 물이 가득 차 있고, 썬글라스를 쓴 캐릭터 주변에 귀여운 튜브와 칵테일이 추가된 화면. 그리고 휴대폰을 기울이면 캐릭터가 그 방향으로 둥실 미끄러지는 것도 추가. (웹/PC 버전에서는 마우스를 클릭한 쪽으로 가도록)
```

해석: 한성부기는 실제 마스코트라 그리지 않고 직접 만든 오리로 대체 · 토글은 로고 옆 [오늘 통계 ⌄] ·
'오늘 등록된 태스크' = 오늘 기한 + 기한 없이 오늘 만든 일 + 오늘 완료한 일 · 50% 미만 구간은 '물 조금 + 서 있음'.

  되튐 곡선은 그림자에 쓰지 않는다(blur 음수 오류 방지, 테스트로 보장).

[화면: 3단 수평 스와이프 + 하단 탭 바 [설정][메인][날짜]]
1) 메인(가운데): keepy 로고 + [오늘 통계 ⌄], (수영장 켰을 때) 오리 얼굴 아이콘(계정 동그라미는 두지 않음), 오늘 날짜,

   태그 관리, 오리 수영장 켜기/끄기(기본 꺼짐), 완료 기록, 샘플 넣기/전체 삭제.
3) 날짜(오른쪽): 기본은 위 1/4 캘린더 고정 + 아래 3/4 고른 날 목록. 캘린더 칸은 둥근 네모,
   할 일 있는 날은 칸을 색으로 채우고 완료 많을수록 진한 초록, 오늘은 그라데이션 숫자+밑줄.
   '2026년 11월' 제목을 누르면 한 달 전체(4~6주)가 펼쳐지고 그만큼 아래 목록이 줄어든다(최대 62%).
   펼친 상태의 < > 는 달 단위. 이전날/다음날 버튼 없음 — 목록 끝에서 70px 넘게 위·아래로 끌고 놓으면
   할 일이 있는 날로만 이동. 이 화면에서 입력하면 고른 날짜가 기한.

[할 일 블럭]
- 둥근 네모 체크박스, 카드 왼쪽 색 막대 없음. 완료 시 체크·취소선 후 완료 목록으로.
- ← 당기기: 날짜 설정만. 당긴 거리에 따라 +1(46px) → +2(104px) → +7(162px) 단계마다 걸리고(햅틱),
  오른쪽에 "+N / 11월 18일 (수)" 배지. 놓으면 오늘+N일로 저장. 누른 채 아래로 28px 내리면 무효.
- → 당기기: 삭제 버튼에 걸리고, 카드 절반 넘게 세게 끌고 놓으면 즉시 삭제.
- 손가락을 1:1 로 따라가지 않고 구간마다 저항·걸림. 삭제 버튼이 열린 채 절반 이상 화면 밖이면 닫힘.
- 블럭 누르면 수정 시트(제목·태그·기한·삭제). 기한은 오늘·내일·모레·다음 주·없음 칩 + 한 달 달력에서 한 번에.
  태그 줄 오른쪽 ⚙ → 태그 관리(추가·이름 변경·삭제·≡ 끌어 순서 변경, 변경·삭제는 할 일에도 반영,
  1~12자, 중복 불가, 최대 12개).

[상태] 기한이 지났거나 기한 없이 N일 지나면 '지연', 지연 중 완료하면 '늦은 완료'.

[입력] 하단 고정 입력 바(전송 화살표, 카메라 버튼). 눌러야 입력 상태, 입력 전 바 위 좌우 밀기 = 탭 전환.
입력 중 키보드 위 태그 칩(사용자 태그 목록). 공백 제외 1~100자일 때만 전송. 빈 입력은 흔들림+안내.
입력 바 위 72px 는 리스트 항목이 작아지며 흐려져 사라지고 터치를 받지 않는 '탭 전환 영역'.

[되돌리기 알림] 직접 만든 알림, 0.6초, 다른 곳 누르면 즉시 닫힘. 완료·삭제·날짜 변경에 '취소'.

[카메라 OCR] 가이드 화면 → 촬영/앨범 → ML Kit 온디바이스 한글 인식 → 줄 단위 후보 → 검토 시트
(글자 수정, 체크박스, '선택한 N개 추가'). 원본 이미지 즉시 삭제, 권한 거부 안내, 미지원 환경은 붙여넣기.

[오리 수영장] (v0.7, 옛 미니게임 자리 · 카메라처럼 3단과 무관한 전체 화면, X 로 나가기)
- 캐릭터: 직접 만든 노란 오리(둥근 머리·주황 부리·볼터치·깃털 한 가닥). 실제 마스코트는 쓰지 않음.
- 설정 > 오리 수영장 스위치(기본 꺼짐). 켜면 메인 머리 오른쪽에 오리 얼굴 아이콘.
- 오늘의 할 일 = 오늘 기한 + 기한 없이 오늘 만든 일 + 오늘 완료한 일. 완료율만큼 텅 빈 수영장에 물이 차오름.
- 0개·완료 0 → 텅 빈 수영장에 서 있음 / 50% 미만 → 물 조금, 서 있음 / 50% 이상 → 둥둥 /
  100% → 가득 + 선글라스·튜브·칵테일·반짝이, 휴대폰 기울기(가속도 센서) 또는 탭·클릭한 쪽으로 미끄러짐.

[오늘 통계] 메인 로고 옆 [오늘 통계 ⌄] → 날짜 화면 월 캘린더처럼 그 자리에서 펼침/접힘.
안경·학사모·엄지 척 오리, 가장 많이 한 태그, 태그별 막대(사용자 태그 포함, 많은 순 최대 5개).

[기술] shared_preferences(JSON), cupertino_icons, image_picker, google_mlkit_text_recognition,
sensors_plus(수영장 기울기), flutter_localizations. 상태는 ChangeNotifier + InheritedWidget,

android/ios/web 은 flutter create 로 만들고 설정 스크립트로 한글 OCR 의존성·iOS 권한 문구 추가.

[산출물] app/lib/(core, models, data, state, services, game, ui/…), app/test/, README.md(MP2 제출용),
README_KEEPY.md(총정리),

docs/PROMPTS.md, TEAM_NOTES.md(개인 브랜치 → 선정본만 main), .gitignore, .env.example,

## D. 프롬프트 잘 쓰는 법

### 1) 한 줄에 하나, 번호 붙이기
지금까지처럼 번호를 붙이면 빠짐없이 처리하고, 정리 문서도 번호별로 대응표를 만들기 쉽습니다.

### 2) '어디서 · 무엇을 · 어떻게 끝나는지'
| 나쁜 예 | 좋은 예 |
|---|---|
| 스와이프 좀 바꿔 | **메인 화면** 할 일 블럭을 **←로 당기면** **날짜만** 나오게. **당긴 거리**에 따라 +1/+2/+7, **놓으면 저장**, 누른 채 **아래로 내리면 취소** |
| 캘린더 크게 | 날짜 화면 **'2026년 11월'을 누르면** 한 달 전체가 펼쳐지고 **아래 목록이 그만큼 줄게**. 다시 누르면 접기 |

### 3) 숫자로 말하기
"조금 더 빨리" 보다 "0.6초", "70px", "+1/+2/+7", "최대 12개"처럼 숫자가 있으면 그대로 반영됩니다.
모르면 "적당히 정해서 알려 줘"라고 쓰면, 정한 값을 IMPLEMENTATION.md 에 적어 둡니다.

### 4) 범위가 애매하면 어떻게 할지 미리 정하기
예: "메인 화면에서"라고 썼는데 날짜 화면에도 같은 블럭이 있을 때 → "날짜 화면에도 똑같이" 또는
"메인에서만"을 덧붙이면 해석 차이가 없습니다. (v0.3 에서는 같은 블럭이라 둘 다 적용했습니다.)

### 5) 기준 문서 우선순위 밝히기
"prompts_log > UI 설계서 > 요구사항 명세서"처럼 순서를 주면 문서끼리 다를 때 판단 기준이 분명해집니다.

### 6) 과제 기준이 있으면 그대로 붙이기
과제 안내 표(제출 산출물·통과 기준)를 사진이나 글로 함께 주면, 폴더 구조·README 필수 항목·스크린샷 이름까지
기준에 맞춰 정리하고 자체 점검표를 만들어 줍니다. (v0.4 에서 `app/` 구조 문제를 이렇게 찾았습니다.)

### 7) 확인 방법까지 요청하기
"웹 미리보기로 화면 확인", "flutter test 통과", "스크린샷으로 보여 줘" 등을 넣으면 결과를 검증한 뒤 받습니다.

### 분야별 예시
```
[디자인] 완료한 일 카드의 배경을 지금보다 더 연하게(#F8FAFD → 거의 바탕색)하고 취소선 색도 한 단계 연하게.
[조작]   ← 당기기 단계를 +1/+2/+3/+7 네 단계로 바꾸고, 단계 사이 거리를 50px 로.
[기능]   할 일에 '메모'(최대 300자) 칸을 추가해서 수정 시트에서 쓰고, 블럭에는 메모가 있으면 작은 아이콘만.
[수영장]   100% 일 때 튜브 색을 노랑·하늘 줄무늬로, 안내 문구는 시간대(아침/저녁)에 따라 다르게.
[버그]   날짜 화면에서 한 달을 펼친 채 다른 달 날짜를 누르면 <증상>. 재현: 1) … 2) … 기대: …
[문서]   README 의 '조작' 표를 스크린샷 3장과 함께 docs/manual.md 사용 설명서로 따로 만들어.
```
