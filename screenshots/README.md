# screenshots

제출용 화면 캡처. **단계별로 요구되는 장면이 다르다.**

## 파일 이름 규칙

`<단계>_<번호>_<화면>.png` — 예: `mp1_01_main.png`

## 찍어야 하는 것

### MP1 — 목록 · 추가 · 완료 · 빈 상태

- [ ] `mp1_01_main.png` — 메인 목록 (할 일 여러 개, 분류가 보이게)
- [ ] `mp1_02_add.png` — 입력 바에 글자를 넣고 태그 칩이 뜬 상태
- [ ] `mp1_03_done.png` — 체크 직후 (취소선 + 토스트)
- [ ] `mp1_04_empty.png` — 빈 상태 화면

### MP2 — 수정 · 삭제 · 필터 · 재시작

- [ ] `mp2_01_edit.png` — 편집 시트 (제목·태그·날짜 휠)
- [ ] `mp2_02_delete.png` — 오른쪽으로 끌어 삭제 버튼이 나온 상태
- [ ] `mp2_03_filter.png` — 전체/미완료/완료 세그먼트
- [ ] `mp2_04_restart_before.png` — 앱 종료 **직전** 목록
- [ ] `mp2_05_restart_after.png` — 다시 켠 **직후** 같은 목록 (저장 증명)

### MP3 — 로그인 · 동기화

- [ ] `mp3_01_login.png` — 로그인 화면
- [ ] `mp3_02_sync_a.png` / `mp3_03_sync_b.png` — 두 기기 같은 계정, 같은 목록
- [ ] `mp3_04_offline.png` — 비행기 모드에서 작성한 상태

### MP4 — 카메라 OCR

- [ ] `mp4_01_capture.png` — 촬영 화면
- [ ] `mp4_02_review.png` — 인식 결과 검토 (줄 단위 체크)
- [ ] `mp4_03_added.png` — 일괄 추가된 뒤 메인 목록

### 그 외 (여유 되면)

- [ ] `extra_01_date.png` — 날짜 화면 (캘린더 1/4 + 목록 3/4)
- [ ] `extra_02_settings.png` — 설정 화면

## 찍기 전에

- **첫 실행 샘플 7개**(`AppState._seed()`)를 그대로 쓸지 지울지 팀에서 정할 것
- 개인정보가 들어간 사진·화면은 올리지 않는다 (CST-04)
