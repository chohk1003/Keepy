# Keepy (키피) — 총정리

> 제스처 중심 할 일 앱 · 팀 프로젝트 #2109 · Flutter · **v0.5.0** (2026-11-15)
>
> MP2 제출용 문서는 [README.md](README.md), 이 문서는 지금까지 만든 Keepy 전체를 한눈에 보는 정리본입니다.

메인 화면을 가운데 두고 왼쪽 **설정**, 오른쪽 **날짜** 화면을 넘겨 쓰는 3단 구조의 할 일 앱입니다.

## 3. 화면 구성

| 화면 | 위치 | 내용 |
|---|---|---|
| 설정 | 왼쪽 | 계정 · **화면 모드(시스템/라이트/다크)** · 알림 · eclass/에브리타임 · 달력 행 수/이번 주 위치/완료율 형태 · 지연 기준 · 태그 관리 · 미니게임 켜기/끄기 · 완료 기록 · 데이터 |
| 메인 | 가운데 | 모든 할 일 · **오늘 요약(오늘 할 일·지연·오늘 완료)** · 전체/미완료/완료 · 지연 → 해야 할 일 → 완료한 일(접기·비우기) · 편집(순서) · 미니게임 바로가기(켰을 때) |
| 날짜 | 오른쪽 | 위 1/4 캘린더(완료 많을수록 진한 초록) · '년 월' 누르면 한 달 전체 · 고른 날 할 일 · 완료율(바/원형/그래프) |
| 할 일 수정 | 시트 | 제목 · 태그(⚙ 관리) · 기한(오늘·내일·모레·다음 주·없음 칩 + 한 달 달력) · 삭제 |
| 미니게임 | 별도 전체 화면 | 이번 달 계단 오르기 · 꾸미기 · X 로 나가기 |
| 카메라 | 별도 전체 화면 | 메모 촬영 → 온디바이스 글자 인식 → 검토 후 일괄 추가 |

## 4. 조작

| 조작 | 동작 |
|---|---|
| 할 일 **← 당기기** | 날짜만 설정. 거리에 따라 **+1 → +2 → +7일** 단계마다 걸리고, 놓으면 저장 |
| 당기는 중 **아래로 내리기** | 취소 (아무것도 안 바뀜) |
| 할 일 **→ 당기기** | 삭제 버튼에 걸림 · 누르거나 절반 넘게 세게 끌고 놓으면 삭제 |
| **편집** (메인) | ≡ 손잡이로 구역 안 순서 바꾸기 |
| 할 일 누르기 | 수정 시트 · 태그 옆 **⚙** → 태그 추가·이름 변경·삭제·**≡ 끌어 순서 변경** |
| 기한 줄 누르기 | **오늘·내일·모레·다음 주·없음** 칩 또는 달력에서 날짜 한 번 누르기 |
| **오늘 요약** 칸 누르기 | 오늘 할 일 → 날짜 화면의 오늘 · 지연 → 미완료 탭 · 오늘 완료 → 완료 탭 |
| **완료한 일** 머리 누르기 / **비우기** | 접기·펼치기 / 완료한 일 모두 지우기 (확인 후, 알림의 '취소'로 되돌리기) |
| 체크박스 | 완료 (0.6초 '취소', 다른 곳 누르면 알림 즉시 닫힘) |
| 좌우로 밀기 (빈 곳·입력 바 위·리스트 맨 아래) | 화면 전환 / 하단 탭 |
| 날짜 화면 목록 끝에서 위·아래로 더 끌기 | 할 일이 있는 이전·다음 날로 |
| 날짜 화면 **'2026년 11월'** 누르기 | 한 달 전체 펼치기 ↔ 접기 |

## 5. 미니게임 — 계단 오르기

- **켜기:** 설정 > 미니게임. 켜면 메인 오른쪽 위에 계단 아이콘, 끄면 사라짐.
- **계단 수** = 이번 달 할 일 수(미완료·지연 포함), **오른 칸** = 완료 수. 1개 끝낼 때마다 1칸.
- **100%** → 정상 도착 + 만세 점프 + 폭죽, 펫도 함께 뜀 / **미달** → 남은 칸 + 격려 문구 + 응원 모션.
- **꾸미기 (v0.4):** 캐릭터 **남자 / 여자 / 내 사진**(온디바이스 AI 로 사람만 오려 24×24 픽셀아트), 펫 **없음 / 강아지 / 고양이 / 토끼**.
- **함께 오르기 (v0.5):** 펫이 캐릭터와 **같은 칸에 나란히** 서서 함께 깡충 오름. 칸은 둘이 겹치지 않을 만큼 넓게 유지하고, 할 일이 많으면 화면이 캐릭터를 따라감. 캐릭터·펫은 둥근 얼굴·옅은 남색 외곽선·눈 반짝임·볼터치로 더 귀엽게.
- 진행 막대, '오늘 +N칸', 다크 모드에서는 별·달이 뜬 밤하늘.

## 6. 다크 모드 (v0.4)

- 설정 > 화면 > **시스템 / 라이트 / 다크**. 시스템은 휴대폰 설정을 따라가고, 휴대폰에서 바꾸면 바로 반영.
- 바탕·카드·글자·구분선·캘린더 농도·탭 바·미니게임 배경이 함께 바뀌고, 하늘색→파란색 강조는 두 모드 공통.
- 모드를 바꿔도 보던 탭이 유지됨.

## 7. 프로젝트 구조

```
Keepy1/
├─ README.md / README_KEEPY.md / prompts_log.md / screenshots/
├─ app/                          Flutter 앱
│  ├─ lib/
│  │  ├─ main.dart, app.dart     시작 · 화면 모드 · MaterialApp
│  │  ├─ core/                   theme(라이트·다크 팔레트, 글꼴, 모션), shadows, dates
│  │  ├─ models/                 Task(순서), TaskStatus(지연·늦은 완료), AppSettings(화면 모드·태그·미니게임)
│  │  ├─ data/                   저장소 계약 + shared_preferences 구현
│  │  ├─ state/                  TaskStore, SettingsStore, KeepyScope
│  │  ├─ services/               OCR, 사진→캐릭터, 사람 분할 AI, 이미지 삭제, 동기화 계약
│  │  ├─ game/pixel_art.dart     픽셀아트 변환, 남/여 캐릭터·펫 그림
│  │  └─ ui/  shell · pages · widgets(task_tile, mini_calendar, tag_manager_sheet …) · game · ocr
│  ├─ test/                      모델·스토어·순서·태그·월 통계·픽셀아트·그림자·위젯(다크 모드·날짜 칩·꾸미기)
│  ├─ assets/fonts/              나눔스퀘어라운드 R/B/EB + OFL 라이선스
│  └─ tool/                      플랫폼 설정 스크립트
├─ preview/                      웹 미리보기 (index.html + 글꼴 일부)
└─ docs/                         IMPLEMENTATION, CHANGELOG, MODIFY_GUIDE, PROMPTS, TEAM_NOTES
```

의존 방향: `ui → state → data/models`, `ui → services → game`. 화면은 저장 방식을 모릅니다.
